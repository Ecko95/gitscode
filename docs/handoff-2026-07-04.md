## Operating gotchas (learned this session — respect these)

- **CI is the only arbiter.** Agents' local "pre-existing failure" claims are unreliable
  (worktree-env artifacts). Trust the quality check on the branch HEAD SHA, not local runs.
- **Verify CI verdict against the branch HEAD SHA before merging** — a green run on a
  pre-fix SHA is not a green PR.
- **Typecheck = `bunx turbo run typecheck --force` (tsgo), NOT plain `tsc`.** tsgo enforces
  custom Effect diagnostics as errors: no node `fs`/`path` imports (use Effect
  `FileSystem`/`Path`), no `new Date()`/`Date.now()` (use `DateTime`/`Clock`). Plain `tsc`
  passes and misleads — this killed one agent for an hour.
- **Final gate: `./node_modules/.bin/oxfmt --check .` clean REPO-WIDE** — several PRs failed
  CI on one missed-format file. Never repo-wide `bun fmt`; format touched paths only.
- **Never `git stash` in agent worktrees** — they share one `.git`; stashes cross-contaminate.
  Use `git diff origin/gits` for baselines.
- **`gh --json` inside scripts is mangled by the RTK hook** — use `rtk proxy gh api` / `gh api`.
- **gh default repo**: `gh` may resolve to the wrong account. Always `--repo Ecko95/gitscode`
  for GITS; `Ecko95/delamain` for delamain (NOT joshuaduffill — that's 404).
- **Every design→implementation gate this session caught a real defect** (adoption semantics,
  approval policy, provider deny-bucket, verify-hashes, inactivity guard). Never merge on an
  agent's report alone — review the diff.

## Pickup 3 — Delamain concurrent-peer auth hardening (medium, delamain repo, needs a decision)

**Problem:** all Codex peers share one `~/.delamain/peer-codex-home`; ChatGPT OAuth refresh
tokens are single-use, so 2+ concurrent Codex peers race and re-trigger `refresh_token_reused`
even after a fresh login. `src/runner.ts:61` sets the shared `CODEX_HOME`.
**Options (operator decision first):** (a) API-key mode for the peer home (static key, no
rotation — most robust; changes billing from ChatGPT plan to API); (b) serialize peer token
refreshes; (c) per-peer CODEX_HOME (needs per-peer login — impractical). Recommend (a).
**Bring a short plan to the operator before implementing** (auth/billing change).

## Pickup 4 — Git-shim: OS-level confinement (large, only if threat model escalates)

**Context:** plan 24 (`.plans/24-git-command-confinement.md`) §5 documents this as the future
tier. The shipped PATH shim (#92) is defense-in-depth for honest-agent accidents; a determined
agent bypasses it (absolute path, libgit2). Real isolation = bubblewrap/namespaces/seccomp
restricting the provider subprocess to its worktree. Linux/WSL-first; macOS needs a separate
mechanism. **Only pick up if adversarial agents become the threat** — otherwise leave.
